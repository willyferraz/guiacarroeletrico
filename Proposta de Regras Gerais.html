Proposta de Regras Gerais

Sistema de Abastecimento de Veículos Eletrificados (SAVE) - Residencial Magnólia

Diretrizes para garantir segurança, isonomia e viabilidade técnica para todos os condôminos. (Clique nos cartões para ler o texto completo)

1. Requisitos Técnicos

  • Obrigatório seguir estritamente o Projeto Elétrico (SAVE).
  • Contratação de engenheiro para projeto individual.
  • ART de Projeto e Execução indispensável.
  • Cumprimento das normas vigentes.

Por que?

Garantir a padronização técnica, a segurança e a conformidade legal frente aos órgãos fiscalizadores.

Clique para ler a regra completa

2. Tipologia (Wallbox)

Autorizado exclusivamente carregador fixo (Wallbox).

VEDADO: Tomadas de uso geral ou carregadores portáteis.

Por que?

Wallbox possui "inteligência" para cortar anomalias. Tomadas comuns criam vulnerabilidade de segurança e risco de uso indiscriminado.

Clique para ler a regra completa

3. Limitação por Unidade

Permitida a instalação de apenas 01 (um) ponto de recarga (Wallbox) por unidade autônoma (apartamento).

Por que?

Assegurar a isonomia e permitir acesso ao maior número de moradores antes de obras complexas.

Clique para ler a regra completa

4. Potência Máxima

Limite: 8 kW
Tipo: Corrente Alternada
Fase: Monofásico

Por que?

Preservar a curva de demanda e evitar sobrecarga prematura do sistema elétrico.

Clique para ler a regra completa

5. Capacidade e Rodízio

Se interessados superarem a capacidade, será instituído sistema de rodízio (uso ou horários) até adequação dos quadros.

Por que?

Garantir benefício justo sem provocar o desarme geral dos disjuntores do prédio.

Clique para ler a regra completa

6. Consultoria Técnica

Taxa paga pelo solicitante para:

  • Revisar projeto executivo.
  • Determinar fase elétrica.
  • Fiscalizar a execução.
  • Gerar registro para o condomínio.

Por que?

Garantir imparcialidade e isenção de custos para os demais moradores.
